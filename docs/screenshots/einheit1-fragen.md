## Einheit 1

- Was ist der Unterschied zwischen Capacitor und Cordova?
Capacitor und Cordova ermöglichen es, Web-Apps wie Ionic-Apps als mobile Apps auszuführen und auf Gerätefunktionen zuzugreifen. Capacitor ist der modernere Ansatz und wird von Ionic verwendet.

- Was macht ein ORM wie Sequelize, und wofür braucht man zusätzlich die sequelize-cli?
Sequelize ist ein ORM, das die Verbindung zwischen Node.js und einer relationalen Datenbank vereinfacht, sodass man nicht alles direkt mit SQL machen muss. Die sequelize-cli wird verwendet, um beispielsweise Models und Datenbank-Migrationen über die Kommandozeile zu erstellen und zu verwalten.

- Was unterscheidet npm install von npx beim Ausführen eines Pakets?
npm install wird verwendet, um ein Paket zu installieren. npx wird verwendet, um ein Paket bzw. dessen Kommando auszuführen, ohne es unbedingt global installieren zu müssen.

- Was ist REST, und warum passt das Konzept zu einer Client-Server-Architektur wie Ionic-App und Node-Backend?
REST ist ein Konzept für die Kommunikation zwischen Client und Server über HTTP. Eine Ionic-App kann dabei als Client Anfragen an ein Node-Backend senden, das die Daten verarbeitet und beispielsweise als JSON zurückgibt.
